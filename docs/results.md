# Recorded results

`results/binary_results.json` and `results/multi_modal_results.json` preserve recorded evaluation output from the project scripts. The preprint reports fine-tuned Vision Transformer performance up to 95% in the described experimental context.

The files are not a substitute for a reproducible evaluation protocol. A future release should record:

- dataset version and SHA-256 manifest;
- label mapping and split seed;
- package and hardware versions;
- model release identifier/checksum;
- complete metrics, including per-class precision, recall, and confusion matrix.
