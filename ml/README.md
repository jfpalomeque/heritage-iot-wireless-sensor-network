# Machine-learning scripts

`training/` contains the original Hugging Face ViT fine-tuning scripts for binary and multiclass classification. `inference/` contains ViT and CLIP experiment scripts, and `diy_anns/` contains exploratory CNN/FNN/RNN work.

These are preserved research scripts, not a packaged training pipeline. Configure dataset and output paths locally; do not add raw images or model binaries to Git. See `../data/README.md`, `../models/README.md`, and `../docs/reproducibility.md`.
