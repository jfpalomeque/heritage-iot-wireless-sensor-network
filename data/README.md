# Dataset status

The original archive contains the behavioural image collections used for binary and eight-class experiments. These files are not included in Git.

The author is the sole photographed participant and holds the rights to the behavioural images. A future public release can therefore be prepared without a third-party image-rights dependency, subject to completing the publication metadata and packaging.

Before any external release, create a versioned dataset package containing:

1. a dataset card describing provenance, consent/legal basis, locations, intended use, risks, and licence;
2. a SHA-256 manifest and exact directory layout;
3. class definitions matching the released label configuration;
4. duplicate detection and split protocol documentation;
5. an access/removal contact and any necessary restrictions.

Until a dataset deposit is created, the companion repository documents dataset size, classes, and historical evaluation results without distributing the images.
